<h2 class="gl-open-h">Every bill, feed, map and line of code is free to use.</h2>
<p class="gl-open-p">Govbot turns government updates into plain git repositories — clone the legislation of <strong>56 jurisdictions in under a minute</strong>, query it with SQL, or build your own tools on top.
